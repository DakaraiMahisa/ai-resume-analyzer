# AI Resume Analyzer

AI-powered resume analysis and job matching platform.

The system is designed to analyze resumes against job descriptions, extract structured information, evaluate candidate-job alignment, and provide evidence-based recommendations.

---

## Project Status

🚧 **Foundation / Initial Development**

The project repository and development environment have been established.

Current foundation:

- Spring Boot backend
- React + TypeScript frontend
- MySQL 8.4
- Docker Compose
- Java 21
- Maven Wrapper
- Vite
- Environment-based configuration

Application features are currently under development.
